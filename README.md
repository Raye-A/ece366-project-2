## Run in MARS

1. Open `fibonacci.asm` in MARS.
2. Change the `.word` next to `n` to the input you want. Use 0 through 47 for an exact result in one unsigned 32-bit word.
3. Choose **Run > Assemble**, then **Run > Go**. The answer appears under **Run I/O** and is stored at `result` (the word after `n` in the Data Segment).

With the default input of 10, the answer is 55.
