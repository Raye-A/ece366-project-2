## How to run in MARS

1. Open `OddOrNot.asm` in MARS.
2. Change the `.word` next to `n` to the input you want. Value already in place is 7.
3. Choose **Run > Assemble**, then **Run > Go**. The answer appears under **Run I/O** and is stored at `result` (the word after `n` in the Data Segment).

The value by default is 7, which should give a result of "True"
